# Quick Music Download

<img align="left" height="65vw" src="https://i.imgur.com/D68JyFZ.png">

Part of the Music Download Suite. It takes a directory full of JSON files, downloads the music from the provided URL, and tags the file with the provided metadata.

Download Here: [https://www.icloud.com/shortcuts/fcd496660a1742e897805eb357b84092](https://www.icloud.com/shortcuts/fcd496660a1742e897805eb357b84092)

---

### Description

This Shortcut should be used in conjunction with the other Shortcuts in the Music Download Suite. It looks in the specified iCloud directory for any JSON files containing music data. It then loops through the stored JSON files, extracts the music URL and metadata from each one, then downloads and tags the music.

This Shortcut will ask to be updated when it needs to. Simply click Update when it asks, or force it to update by passing ```--update``` as the input.

> [!NOTE]
> This Shortcut can only be run on a Mac.
